How Mirepoix could look and feel

These are static drawings to react to, not the app. There are six screens across the first three releases, and each one is tagged with the release it arrives in. Sample recipes are made up; sources are fictional. Reasoning lives in DECISIONS.md, and the order of work in TASKBOARD.md.

Design notes

OnionPaper and backgrounds
CarrotActions, section headings, the current step
Celery“All good”: sync, ticks, cook’s notes
InkText, with a softer ink for secondary text
  • Type. Recipe text is set in a bookish serif that’s already on your device (Iowan Old Style on Apple, Palatino on Windows). Controls use the system font. There are no web fonts to download.
  • Light and dark follow the system. The toggle at the top flips this page.
  • Reading never edits. There’s no inline editing and no autosave. Edit is its own screen with Save and Cancel, and cook mode can only add notes.
  • Flag, don’t guess. When the parser isn’t sure, it says so and keeps your words.
  • Big targets. Anything you tap is at least 44 px. Cook-mode type is readable at arm’s length.
  • Not drawn yet: smart paste (R4) and your own units (R5).
